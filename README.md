# JARVIS WorkOS

Голосовой ассистент для Omarchy Linux: окно-компаньон, локальные команды без ИИ, Claude (через Claude Code) для свободных
вопросов и действий,
единая система разрешений и проверяемые результаты.

## Запуск

```bash
cd ~/Projects/jarvis
scripts/install.sh            # команда `jarvis` + пункт «JARVIS» в меню приложений (без root)
jarvis                        # запускает ядро (если не запущено) и открывает окно
```

Необязательно:

```bash
scripts/install.sh --service          # ядро как служба systemd --user (старт при входе)
scripts/omarchy-integrate.sh apply    # индикатор в Waybar + Super+H / Super+Shift+H (с резервной копией)
scripts/omarchy-integrate.sh remove   # убрать интеграцию
```

Другие команды: `jarvis status`, `jarvis stop` (экстренная остановка), `jarvis resume`, `jarvis say "текст"`.

## Компаньон на рабочем столе

Маленький JARVIS поверх всех окон и рабочих столов (правый верхний угол): нажмите — откроется карточка с ответами,
планом и подтверждениями, перетащите — переместится в любое место экрана. Включите микрофон в карточке, и достаточно
сказать «Джарвис, …» — речь распознаётся на этом компьютере, фразы без «Джарвис» сразу отбрасываются и не сохраняются.
`jarvis overlay` или Super+Shift+J — показать; запускается вместе с системой (после `scripts/omarchy-integrate.sh apply`).

## Саморазвитие

Если JARVIS чего-то не умеет, он не отказывает: находит готовый инструмент (GitHub, pip, npm, cargo), ставит его для
пользователя без sudo, оформляет навык (`~/.local/share/jarvis-skills/<имя>`) и проверяет на примере — дальше пользуется
им сам. У навыка есть фразы запуска («сделай qr код для …», «make a qr code for …»): по ним JARVIS запускает его сразу,
без ИИ и без токенов. Ограничений на время работы нет: остановить можно кнопкой «Стоп» или словом «стоп».

## Примеры команд

«Состояние системы» · «Какие окна открыты» · «Переключись на третий рабочий стол» · «Громкость 40» ·
«Открой калькулятор» · «Найди файл смета» → «Открой второй» · «Запиши заметку: позвонить фабрике» ·
«Напомни через 10 минут проверить почту» · «Сделай скриншот» · «Расскажи что-нибудь» ·
«Первое, открой браузер. Потом покажи загрузки» · «Перейди в задачи» · «Домой» · «Пауза» / «Продолжи» / «Отмени» / «Стоп».

Клавиши: `Ctrl+K` — все команды · `Ctrl+J` — спросить JARVIS из любого раздела · `Ctrl+1…9` — разделы · `Ctrl+Space` — фраза голосом · `Esc` — закрыть / остановить · `Ctrl+Shift+X` — экстренный стоп.

## Устройство

```
окно (Chromium --app, web/: оболочка app.js, компаньон ui/, разделы workspaces/, адаптеры adapters/, логика core/)
        ⇄  WebSocket (127.0.0.1, токен + cookie + проверка Origin/Host)
        │                                   │
Waybar-модуль (SSE, bearer)          ядро jarvis/ (Python, aiohttp)
                                       ├─ router.py      — команды без ИИ (уровень 0/1)
                                       ├─ director.py    — задачи, пауза/отмена/стоп, сообщения по расписанию
                                       ├─ gateway.py     — единственный путь к инструментам
                                       ├─ policy.py      — риск, подтверждения (digest), сессионные разрешения
                                       ├─ tools/         — система, файлы, рабочий стол
                                       ├─ scheduler.py   — напоминания
                                       ├─ providers/claude_chat.py — постоянный Claude Code (stream-json), инструменты JARVIS по MCP
                                       ├─ mcp_bridge.py  — MCP-сервер: вызовы Claude → Gateway (подтверждения, аудит)
                                       ├─ voice/         — GigaAM + Parakeet (речь → текст), Silero + Kokoro (голоса), языки
                                       └─ comms/         — Telegram, WhatsApp, почта, очередь отправки
SQLite: ~/.local/share/jarvis/jarvis.db · журнал аудита: ~/.local/state/jarvis/audit.jsonl
ИИ: вход Claude Code на этом компьютере (без API-ключей). Сессии мессенджеров и пароли: GNOME Keyring, не в файлах и не в журналах.
```

## Разработка

```bash
uv run pytest -q                                      # ~360 тестов (+6 живых с настоящим Claude: JARVIS_LIVE=1)
node --test tests/ui/unit/                            # логика окна: состояние компаньона, задачи, геометрия, команды
node tests/ui/workos.mjs <port> <token-file> /tmp/w   # сквозная проверка окна на изолированном ядре (LIVE=1 — с Claude)
uv run python scripts/voice_latency.py /tmp/v "Что такое API?"   # замер голосовой задержки
uv run python scripts/bench.py 40                     # задержки локальных команд
scripts/dev-server.sh start /tmp/jh                   # изолированное ядро (порт из /tmp/jh/config/config.toml)
cd tests/ui && npm install && node drive.mjs <port> <token> <out> smoke   # снимки UI
```

Зависимости: google-genai 2.31.0 (Apache-2.0), aiohttp 3.14.5 (Apache-2.0/MIT);
для тестов UI — playwright-core (Apache-2.0) с системным Chromium. Персонаж-компаньон нарисован с нуля.
