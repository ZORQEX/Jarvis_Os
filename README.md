# JARVIS WorkOS

Голосовой ассистент для Omarchy Linux: окно-компаньон, локальные команды без ИИ, Claude (через Claude Code) для свободных
вопросов и действий,
единая система разрешений и проверяемые результаты.

## Запуск

```bash
cd ~/Projects/jarvis
scripts/install.sh            # команда `jarvis` + пункт «JARVIS» в меню приложений (без root)
jarvis                        # запускает ядро (если не запущено) и открывает окно
```

Необязательно:

```bash
scripts/install.sh --service          # ядро как служба systemd --user (старт при входе)
scripts/omarchy-integrate.sh apply    # индикатор в Waybar + Super+H / Super+Shift+H (с резервной копией)
scripts/omarchy-integrate.sh remove   # убрать интеграцию
```

Другие команды: `jarvis status`, `jarvis stop` (экстренная остановка), `jarvis resume`, `jarvis say "текст"`.

## Claude Code — мозг JARVIS

Всё, что требует ума, делает Claude Code, уже установленный на этом компьютере (ваш вход Claude, без ключей API;
ADR-005, ADR-009). Путь просьбы: голос → распознавание на компьютере → если вся просьба — одна быстрая команда
(«громкость 40», «сколько места на диске»), она выполняется сразу без ИИ; всё остальное получает постоянная беседа
Claude с памятью разговора. Claude сам решает, чем действовать: инструменты JARVIS (файлы, приложения, заметки,
напоминания, поиск, сообщения, «Заказы»…), задание для Claude Code в терминале (сайт, программа, код), быстрый поиск,
Hermes и OpenClaw. Каждое действие проходит через проверку и подтверждение JARVIS; ответ звучит по мере написания.

- **Видно, что он делает:** в задаче и у компаньона — «Ищу в интернете: …», «Создать заметку», «Читаю страницу …»;
  важные действия — карточка и вопрос голосом «Разрешить?», можно ответить «Джарвис, да». «Стоп» прерывает сразу.
- **Составные просьбы целиком:** «узнай, сколько места на диске, и запиши это в заметку» — Claude делает обе части
  (раньше быстрая команда отвечала только на первую).
- **Если Claude недоступен — простыми словами:** «Лимит Claude исчерпан — снова заработает в 4:00» (вслух: «вернётся в
  4 утра»), «Claude вышел из аккаунта — нужно войти заново», «нет связи». Простые команды при этом работают.
  Перегружена модель — отвечает запасная (видно в задаче); Claude завис на 3 минуты без единого признака работы —
  JARVIS останавливает его и со следующей просьбой запускает заново. Длинную работу (сайт, установка, ваше
  подтверждение) это не прерывает.

Настройки в `~/.config/jarvis/config.toml` (любой раздел): `claude_chat_model` (беседа текстом, `claude-sonnet-5-5`),
`claude_voice_model` (ответы голосом, `claude-haiku-5-5`), `claude_fast_model` (разбор команд), `claude_fallback`
(запасные модели, `true`), `claude_timeout_s` (предел одного ответа, `0` — без предела), `max_tool_rounds` (действий
в одном ответе, `0` — без предела), `claude_model` (задания Claude Code). Вход — один раз: `claude` в терминале, затем
`/login`.

## Заказы (фабрики, клиенты, предоплаты)

Модуль заказов (код [alina-fashion-ai](https://github.com/morph-rq/alina-fashion-ai) в папке `fashion/`) — часть
JARVIS: его разделы (Обзор, Заказы, Фабрики, Клиенты, Документы) — вкладки рабочего пространства «Заказы» в оформлении
JARVIS, отдельного ассистента у него нет. JARVIS сам запускает модуль (данные — `~/.local/share/jarvis/fashion`):
готовые правила модуля отвечают сразу, остальное отвечает беседа JARVIS с инструментами модуля. Ничего не сохраняется
без «Подтвердить» на карточке в чате JARVIS или «да, сохрани» голосом (оплаты, условия фабрики и перенос вещей —
только кнопкой); файлы Excel и PDF появляются кнопками под ответом. Примеры: «Джарвис, посчитай предоплаты»,
«Какая вещь у AA самая дорогая?», «Сделай Excel и PDF для IDS», «Открой Dior Cruise», «Загрузи последний файл фабрики
из загрузок». PDF фабрики (проформа) создаёт заказы так же, как Excel: позиции, фото, размеры, клиенты, процент;
все страницы приложения на русском. Обновления приложения: `git subtree pull --prefix=fashion https://github.com/morph-rq/alina-fashion-ai.git main --squash`.

## Быстрый поиск в интернете

Поисковый модуль из jarvis-os друга работает внутри JARVIS: свой локальный SearXNG (DuckDuckGo, Brave и новости
одновременно; ставит `scripts/install.sh`), выдержки только по вопросу со страниц, номера источников [1], [2] со
ссылками. «Найди …» сначала ищет (1–3 с, без запуска ИИ), затем Claude отвечает по найденному; найденное помнится в
разговоре — «теперь используй это в моём проекте» передаёт его Claude Code. Цена биткоина и курсы валют — сразу из
источника, без поиска и ИИ (~0,4 с). Если поиск недоступен — Claude ищет сам, и JARVIS об этом пишет.

## Excel и таблицы

JARVIS сам открывает таблицы — xlsx, xlsm, xls, ods, csv — без запуска Claude Code: «Что в файле «Продажи.xlsx»?»,
«Какая выручка и какой товар продаётся лучше?», «Сколько принёс Иванов в марте?», «Сколько клиентов из Алматы в
Клиенты.csv?», «Создай Excel «Бюджет на ноябрь» с итогами формулами», «Добавь в расходы строку «Связь» на 6 000»,
«Сделай сводную по регионам и месяцам новым файлом». Числа считает сам JARVIS по строкам файла, точно (строка «Итого»
в расчёт не входит), а Claude только пишет ответ. Посмотреть и посчитать — без подтверждения; создать или изменить
файл — после «Разрешить», прежняя версия сохраняется в резервную копию, формулы сдвигаются, как в Excel, и
пересчитываются (LibreOffice). Файл с диаграммами или сводными таблицами на месте не меняется — изменённая копия
сохраняется рядом. Таблицы из «Заказов» (файлы фабрик) по-прежнему загружаются в «Заказы».

## Возможности: OpenClaw, Hermes и агенты на компьютере
Раздел «Возможности» (Ctrl+8) — то, что JARVIS умеет сверх своих инструментов (из morph-rq/jarvis-os, ADR-008):
- **Hermes** — помощник для долгой многошаговой работы: «Поручи Гермесу собрать поставщиков тканей в Италии в таблицу».
  Ищет через быстрый поиск JARVIS, рискованные шаги — только после вашего «да» в окне JARVIS.
- **OpenClaw** — навыки и плагины (GitHub, Notion, Obsidian…), каталог ClawHub (установка только проверенных версий
  после вашего подтверждения, обновления с откатом), каналы: свой Telegram-бот, WhatsApp, Slack, Discord, Signal.
  Запускается сам, когда нужен, и засыпает без дела (иначе держит ~1,5 ГБ памяти).
- **На компьютере** — что делают Claude Code (оба аккаунта) и Codex: «Джарвис, что делают агенты?»; по желанию —
  ответ на их запросы разрешений кнопкой в окне JARVIS (без ответа они спрашивают в терминале, как обычно).
Оба агента думают через ваш вход в Claude Code — ключи API не нужны. Установка: `scripts/install-agents.sh`
(входит в `scripts/install.sh`; без неё: `JARVIS_NO_AGENTS=1`).

## Компаньон на рабочем столе

Маленький JARVIS поверх всех окон и рабочих столов (правый верхний угол): нажмите — откроется карточка с ответами,
планом и подтверждениями, перетащите — переместится в любое место экрана. Включите микрофон в карточке, и достаточно
сказать «Джарвис, …» — речь распознаётся на этом компьютере, фразы без «Джарвис» сразу отбрасываются и не сохраняются.
`jarvis overlay` или Super+Shift+J — показать; запускается вместе с системой (после `scripts/omarchy-integrate.sh apply`).

## Саморазвитие

Если JARVIS чего-то не умеет, он не отказывает: находит готовый инструмент (GitHub, pip, npm, cargo), ставит его для
пользователя без sudo, оформляет навык (`~/.local/share/jarvis-skills/<имя>`) и проверяет на примере — дальше пользуется
им сам. У навыка есть фразы запуска («сделай qr код для …», «make a qr code for …»): по ним JARVIS запускает его сразу,
без ИИ и без токенов. Ограничений на время работы нет: остановить можно кнопкой «Стоп» или словом «стоп».

## Устройство

```
окно (Chromium --app, web/: оболочка app.js, компаньон ui/, разделы workspaces/, адаптеры adapters/, логика core/)
        ⇄  WebSocket (127.0.0.1, токен + cookie + проверка Origin/Host)
        │                                   │
Waybar-модуль (SSE, bearer)          ядро jarvis/ (Python, aiohttp)
                                       ├─ router.py      — команды без ИИ (уровень 0/1)
                                       ├─ director.py    — задачи, пауза/отмена/стоп, сообщения по расписанию
                                       ├─ gateway.py     — единственный путь к инструментам
                                       ├─ policy.py      — риск, подтверждения (digest), сессионные разрешения
                                       ├─ tools/         — система, файлы, рабочий стол
                                       ├─ scheduler.py   — напоминания
                                       ├─ providers/claude_chat.py — постоянный Claude Code (stream-json), инструменты JARVIS по MCP
                                       ├─ mcp_bridge.py  — MCP-сервер: вызовы Claude → Gateway (подтверждения, аудит)
                                       ├─ voice/         — GigaAM + Parakeet (речь → текст), Silero + Kokoro (голоса), языки
                                       └─ comms/         — Telegram, WhatsApp, почта, очередь отправки
SQLite: ~/.local/share/jarvis/jarvis.db · журнал аудита: ~/.local/state/jarvis/audit.jsonl
ИИ: вход Claude Code на этом компьютере (без API-ключей). Сессии мессенджеров и пароли: GNOME Keyring, не в файлах и не в журналах.
```
